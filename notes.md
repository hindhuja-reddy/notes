# Full-Stack Internship Summary

## 1. Full-Stack Basics

### Q: What is Full-Stack Development?

**Answer:** Full-stack development means working with the **frontend, backend, database, APIs, and deployment** of an application.

**Simple flow:**

```text
Frontend → API → Backend → Database
```

### Q: What is Frontend?

**Answer:** Frontend is the **part of the application that users see and interact with**.

**Example:** Buttons, forms, pages, cards, menus, and images.

### Q: What is Backend?

**Answer:** Backend handles the **application logic, requests, and data processing**.

### Q: What is a Database?

**Answer:** A database is used to **store and manage application data**.

**Example:** Users, products, orders, and other application information.

### Q: What is an API?

**Answer:** An API allows the **frontend and backend to communicate with each other**.

### Q: What is Deployment?

**Answer:** Deployment means **putting an application on a server or cloud so users can access it online**.

### Q: How do they work together?

**Answer:**

```text
User
 ↓
Frontend
 ↓
API
 ↓
Backend
 ↓
Database
 ↓
Backend
 ↓
API
 ↓
Frontend
 ↓
User
```

**Answer:** React is a **JavaScript library used to build user interfaces**.

**Example:** Navbar, Food Card, Cart, Login Form.

### Q: What is Node.js?

**Answer:** Node.js allows us to **run JavaScript outside the browser**, mainly for backend development.

**Answer:** Express.js is a **Node.js framework used to build backend applications and APIs**.

Example:

```text

```

Example:


**Answer:**


# 5. HTTP & API Basics

### Q: What is HTTP?

**Answer:** HTTP is a **protocol used for communication between a client and a server**.

### Q: What is GET?

**Answer:** GET is generally used to **retrieve data**.

```text
GET /users
```

### Q: What is POST?

**Answer:** POST is generally used to **send or create data**.

```text
POST /users
```

### Q: What is a request?

**Answer:** A request is a **message sent from the client to the server**.

### Q: What is a response?

**Answer:** A response is the **result sent from the server back to the client**.

```text
Frontend
   ↓ Request
Backend
   ↓ Response
Frontend
```

# 6. React Basics

### Q: What is a component?

**Answer:** A component is a **reusable part of a React UI**.

Examples:

```text
Navbar
Button
FoodCard
LoginForm
Footer
```

### Q: Why use components?

**Answer:** Components make the UI **reusable, organized, and easier to maintain**.

### Q: What are props?

**Answer:** Props are **data passed from one React component to another**.

Example:

```text
FoodCard
  ↓
foodName
price
image
```

### Q: What is state?

**Answer:** State is **data that can change inside a component and update the UI**.

Example:

```text
Cart quantity:
1 → 2 → 3
```

# 7. JavaScript Basics

### Q: What is a variable?

**Answer:** A variable is used to **store a value**.

```javascript
let name = "Hindhuja";
let age = 22;
```

### Q: What is a function?

**Answer:** A function is a **reusable block of code that performs a task**.

```javascript
function add(a, b) {
    return a + b;
}
```

### Q: What is an array?

**Answer:** An array stores **multiple values in one variable**.

```javascript
let foods = ["Pizza", "Burger", "Biryani"];
```

### Q: What is an object?

**Answer:** An object stores **data as key-value pairs**.

```javascript
let user = {
    name: "Hindhuja",
    age: 22
};
```

### Q: What is JSON?

**Answer:** JSON is a **format commonly used to exchange data between frontend and backend**.

```json
{
  "name": "Hindhuja",
  "age": 22
}
```

### Q: What is asynchronous programming?

**Answer:** It allows the application to **continue other work while waiting for an operation such as an API request to finish**.

# 8. Database Basics

### Q: SQL vs NoSQL?

**Answer:**

```text
SQL   → Tables and rows
NoSQL → Flexible document-based data
```

### Q: Why MongoDB?

**Answer:** MongoDB is a **NoSQL document database** that stores data in a flexible document format.

### Q: What is a MongoDB document?

**Answer:** A document is **one record stored in MongoDB**.

### Q: What is a collection?

**Answer:** A collection is a **group of related MongoDB documents**.

```text
Database
   ↓
Collection
   ↓
Documents
```

### Q: What is CRUD?

```text
C → Create
R → Read
U → Update
D → Delete
```

# 15. Git & GitHub

### Q: What is Git?

**Answer:** Git is a **version control system used to track changes in code**.

### Q: What is GitHub?

**Answer:** GitHub is an **online platform for storing Git repositories and collaborating on projects**.

### Q: Git vs GitHub?

```text
Git     → Version control
GitHub  → Online platform for Git repositories
```

### Q: What Git commands do you know?

```bash
git init
git add .
git commit -m "message"
git push
git clone <repository-url>
```

### Q: What does `git init` do?

**Answer:** It **initializes Git in a project** and creates a Git repository.

### Q: What does `git add .` do?

**Answer:** It **adds changed files to the staging area**.

### Q: What does `git commit` do?

**Answer:** It **saves the staged changes as a commit**.

```bash
git commit -m "Add new feature"
```

### Q: What does `git push` do?

**Answer:** It **uploads committed changes to the remote repository, such as GitHub**.

### Q: What does `git clone` do?

**Answer:** It **copies a repository from GitHub to the local computer**.

### Q: Basic Git workflow?

```text
Create / Clone Project
       ↓
Write / Change Code
       ↓
git add .
       ↓
git commit -m "message"
       ↓
git push
```

### Q: What if they ask about a Git command you don't know?

**Answer:**

> "I haven't encountered that command yet. I have mainly worked with basic commands like git init, git add, git commit, git push, and git clone."

**Don't unnecessarily learn or claim commands like:**

```text
git rebase
git stash
git cherry-pick
git reset
git merge
```

unless you actually use them.

# 16. If You Don't Know an Answer

### If you completely don't know:

> "I haven't encountered that yet."

### If you partially know:

> "I haven't worked with it directly, but my understanding is..."

### If you used it but forgot the term:

> "I don't remember the exact terminology right now, but I can explain how I used it."

### If you need a moment:

> "Let me think about that for a second."

### Don't do this:

```text
Guess
↓
Invent technical terms
↓
Get follow-up questions
↓
Get stuck
```

Just be honest and explain what you actually know.

